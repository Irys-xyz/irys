# Index-bench examples

These scripts ran `submodule-index-bench` on the lab host. That binary is not in this branch. Nothing here is called by `irys-sm-bench` or by CI.

The paths, device names, and binary checksums are the lab host's. Do not point them at a live node database.

`presets.py` prints a preset table from that bench's stdout. `../sysfs-orig.example.txt` is the shape of a recorded queue file.
